## 节与节之间为什么这样排

随后逐一检查了正文 75 节和附录 4 节，在每个节标题后补写或改写了一个自然段。绪论第 0.3 节用同一束原子说明第 1 至 3 章的次序。挡住一个出口，可以制备确定的自旋态。转动下一台磁体，同一制备却给出不同的计数，这促使读者区分态与测量。把两台仪器固定，只改变原子在横向磁场里停留的时间，计数仍然会变，这才需要时间演化。随后回到氢光谱时，同样可以逐步追问能级差怎样决定峰的位置，光与原子的相互作用又怎样决定哪些跃迁更强。

## 记号与严谨性的取舍

删除线性空间公理式的开篇。态、演化和测量统一使用 Dirac 记号；不围绕空间振幅的微分方程组织内容。位置与动量的连续基分量仍在必要处出现：例如算符定义域的边界条件、连续归一化与散射矩阵元。这样保留了物理所需的空间信息，也不把选择表象误认作改变物理态。

有限维 Hermite 矩阵与自伴等价；对无界算符则同时给出作用规则与定义域。区间动量的 Dirichlet 定义域只是对称，固定相位边界条件给出不同的自伴实现；硬墙动能不能随意当作前者的平方。另说明广义态不属于通常 Hilbert 空间、连续谱概率属于区间，以及算符乘积所需的定义域。

全文采用 SI 单位制、固定时间和旋转相位约定，区分角频率和 Hz、正则与机械动量、概率与振幅密度、谱辐亮度与能量密度谱。

## 重点核对的计算与条件

| 主题 | 核对与限制 |
| --- | --- |
| 不确定关系 | 从 Cauchy–Schwarz 推出含协方差项的关系；未定义的算符乘积改用内积形式，时间尺度不解释成短时能量不守恒。 |
| 两态驱动 | 明确旋转场的精确解与线偏振场的旋波近似；核对 Rabi 失谐、脉冲角度、Ramsey 相位及频率中的二倍因子。 |
| 热辐射 | 保留两横向偏振；区分频率谱与波长谱的 Jacobian，不能直接用一个谱峰的频率换算另一个谱峰。 |
| Coulomb 代数 | 核对 Runge–Lenz 的排序、量子修正、两个角动量代数和主量子数；能谱与精细结构所需径向矩阵元分别标明推导和来源。 |
| 微扰与变分 | 检查能量分母、二阶符号与态归一化；近简并先对角化；变分上界不等于误差界，残差小也不单独确定能级标签。 |
| 黄金规则与辐射 | 有限时间窗先于极限；核对场正负频分解中的 1/2、态密度、偏振求和与能量 δ 函数的 Jacobian。自由空间发射率不直接外推到腔或介质。 |
| 规范与 Landau | 保留随时间规范变换的额外导数项；核对电荷符号、机械动量对易子、环边界相位、磁通简并度。单粒子层容量不等于完整平台理论。 |
| 全同与纠缠 | 对非正交单粒子态重新归一化；未反对称化两体矩阵元对应 1/2 系数；局部混合不等于联合态无纠缠，Bell 推导明确局域性和设置独立条件。 |
| 散射 | 固定连续基归一化和通量，核对 T 到截面的因子、Yukawa Fourier 核、光学定理的同阶比较及一维 δ 势束缚极点。 |
| 绝热与开放系统 | 局部小参数不充当任意长时充分条件；核对 Berry 符号；区分环境近似与一般 Kraus 操作，核对布居和相干的不同衰减率。 |
| 精细结构 | 固定点核约定，合并相对论动能、旋轨和 Darwin 三项；单独处理 ℓ=0，不能用 0 乘发散径向矩；约化质量替换不声称包含全部反冲。 |

## 验证记录与边界

可重复运行：

~~~sh
python3 scripts/build_notes.py QM
python3 scripts/check_quantum_formulas.py
~~~

数值脚本需要 NumPy 2 或更新版本，计算独立于 LaTeX 源码。十四组检查分别使用：

1. 实验室系含时 Hamilton 矩阵的 RK4 积分核对旋转场 Rabi 解，以及矩阵演化核对 Ramsey。
2. 截断谐振子矩阵核对低能矩、相干态和四次势变分上界；以两种截断尺寸比较低能结果，未声称有限矩阵满足完整正则对易关系。
3. 角动量矩阵及两个自旋的交换算符核对代数和单态、三重态。
4. 随机 Hermite 扰动的精确对角化核对二阶能移，并检查剩余误差随扰动立方缩放。
5. 数值积分核对 Planck 积分、波长峰值和横向偏振角积分。
6. 联合密度矩阵核对部分迹、CHSH、局部操作无信号和路径记录的干涉可见度；另用不同维数的复系数矩阵核对 Schmidt 右基的共轭约定及两侧约化谱。
7. 闭路相邻态重叠的离散乘积核对 Berry 相位及符号。
8. 直接积分主方程核对布居、相干、迹和正性。
9. 独立求解一维接触相互作用匹配条件，以及数值角积分核对分波光学定理。
10. 分别合并精细结构三项，再与点核 Dirac 能谱比较遗漏项的六阶缩放。
11. 对一般四维奇、偶矩阵直接求精确谱，与四阶 Foldy–Wouthuysen 有效算符比较，检验遗漏误差的六阶缩放。
12. 直接对角化自旋轨道耦合矩阵核对 Landé 因子和四条 Zeeman 谱线，并对二能级 Stark 能量作数值微分核对诱导偶极矩。
13. 对有限转速磁场的实验室系 Hamilton 算符作 RK4 积分，再投影到瞬时本征态，核对精确泄漏概率，包含正反转速。
14. 数值积分Gauss 频谱核对 HOM 曲线，以矩阵乘积核对自旋回波，以 Lindblad 积分核对有限时间振幅阻尼的 Kraus 映射。
